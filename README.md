# Hotel Management System

## Project Overview

The Hotel Management System is a web-based application designed to simplify hotel operations and improve the customer experience. It provides separate dashboards for users and administrators to manage room bookings, food orders, customer complaints, and hotel staff.

Users can register and log in using their credentials, book rooms, order food, and raise complaints directly through the website. Administrators can manage hotel operations through an admin dashboard.

## Features

### User Dashboard
- User registration and login.
- View and select available hotel rooms.
- Choose the number of guests.
- Book rooms according to availability.
- Order food directly through the website.
- Raise complaints or report room-related issues.
- Manage and view booking details.

### Admin Dashboard
- Admin login and dashboard access.
- View available and occupied rooms.
- Manage room availability and bookings.
- View customer food orders and manage order serving.
- View and manage customer complaints.
- Manage hotel workers and staff.
- Monitor hotel operations.

## Technologies Used

- **Frontend:** React.js, JavaScript, HTML, CSS
- **Styling:** Tailwind CSS
- **Backend:** Node.js
- **Database:** MongoDB
- **Development Tool:** Vite

## Database

MongoDB is used to store and manage application data, including:
- User details
- Room information
- Booking details
- Food orders
- Customer complaints
- Staff information

## How It Works

1. Users register or log in to the website.
2. Users select a room based on availability and the number of guests.
3. Users can book rooms and order food online.
4. If customers face any issues, they can raise complaints through the website.
5. Administrators monitor room availability, customer bookings, food orders, and complaints.
6. Admins can manage hotel workers and coordinate hotel services.

## Project Objective

The main objective of this project is to digitize hotel management operations, reduce manual work, simplify room booking and food ordering, and provide an efficient platform for both customers and hotel administrators.
